# QuantDesk 5 分钟演示脚本（Lead 截图 / 录屏用）

> 版本 v1.1 · 2026-10-26 · 用途：一次录屏走完「拉数据 → 看推荐 → 看筛选 → 跑回测 → 模拟买入 → 看持仓 → 触发自动化」
> 原则：每步只做一个动作；画面里出现的按钮/文案与本脚本一致；数字以你机器上实际显示为准（§3 给了参考基线）。

## 0. 录制前检查（约 2 分钟，务必做完）

- **启动**：双击 `quantdesk\scripts\start.bat`，黑窗口保持打开；浏览器打开 <http://localhost:8501>。
- **状态灯**：侧边栏「数据库=就绪」「日志=已启用」；黄色警告先处理（数据库没就绪会导致下单/回测失败）。
- **账户**：总览页总资产 100,000.00 元、可用资金 100,000.00 元、无持仓（持仓页确认）。
- **数据**：行情页能出 K 线（本机缓存 3 只：`600519.SH` / `000001.SZ` / `300750.SZ`，最新数据 2026-10-23）。
- **时段二选一**：
  - **A 路径**（交易日 09:30–11:30 或 13:00–15:00）→ 第 6 步能真正成交，第 7 步能看到持仓；
  - **B 路径**（其它时间，含晚上/周末/节假日）→ 第 6 步会变成"风控拦截演示"（RK005），第 7 步为空态（见 §5 兜底）。
- **今日推荐 / 全市场筛选**：先各点开一次，确认能出列表、顶部有「研究阶段」提示（推荐页已修复；筛选页当前是原型规则）。口播必须说清「研究阶段、不构成买入建议」。
- **屏幕**：浏览器缩放 100%，窗口 ≥1280×800；关掉无关标签，鼠标别压在导航上。

## 2. 分步脚本

### 第 1 步（0:00–0:25）开场：这是什么
- **位置**：侧边栏顶部 + 总览页。
- **操作**：鼠标停在侧边栏底部「模式：模拟盘 · 实盘未接入」「个人非商业研究用途 · 不构成投资建议」。
- **期望**：状态灯 4 个（数据源/调度器/数据库/日志）；6 个 KPI（总资产 100,000.00）。
- **截图**：`shots/01_overview.png`（含侧边栏 + KPI）。
- **口播**：「这是本地运行的量化交易工作台，只做模拟盘，不接真实资金，也不承诺收益。」

### 第 2 步（0:25–1:10）拉数据：行情页出 K 线
- **位置**：侧边栏「📈 行情」。
- **操作**：确认「标的」下拉是 `600519.SH`（默认就是）→ 确认区间「近 1 年」（默认就是）→ 点「🔄 拉取/刷新数据」，等 2–5 秒。
- **期望**：出现日 K 线 + MA5/10/20/60 + 成交量；下方显示「最新价（收盘）」「涨跌幅」「成交额」；数据来源写"本地缓存 / 数据源直连"。
- **截图**：`shots/02_market.png`（K 线 + 右侧最新价同框）。
- **口播**：「行情先落到本地数据库，之后断网也能看；这是公开延迟数据，不是实时行情。」

### 第 3 步（1:10–1:55）看推荐：两份榜单（研究阶段）
- **位置**：侧边栏「🎯 今日推荐」。
- **操作**：先停在「全市场短线雷达」页签，让顶部「⚠️ 研究阶段提示」入画 3 秒；再切到「自选池长期精选」。
- **期望**：候选列表（代码/现价/涨跌幅/成交量比/突破幅度/推荐理由与得分拆解）+ 状态条（候选、入选、策略、数据源）+ 每行风险提示；「全市场短线雷达」页签顶部有「⚠️ 研究阶段提示」，状态条有「免责：仅供研究，不构成投资建议」。
- **注意**：本步只看不买；「加入自选」只是写进自选池，不会下单。
- **截图**：`shots/03_recommend.png`（要拍到研究阶段提示 + 至少 2 行推荐理由）。
- **口播**：「短线榜还在研究阶段，用规则打分，不是买入建议；系统没有任何一键买入入口。」

### 第 4 步（1:55–2:35）看筛选：全市场规则候选（研究阶段）
- **位置**：侧边栏「🔎 全市场筛选」。
- **操作**：保持「流动性前 N=300」「Top N=25」「剔除过热（涨幅≥9.5%）」勾选 → 点「🔄 刷新扫描」。
- **期望**：顶部「合规提示」+（正式筛选服务未接入时）「原型规则，验证中」；状态条显示全市场总数/流动性过滤后/本次扫描/数据时间/规则；下方结果表（代码/名称/现价/涨跌幅/成交额/得分/入选理由/风险标记），行尾有「加入自选」。
- **截图**：`shots/03b_screener.png`（要拍到两张警示卡 + 状态条）。
- **口播**：「这是全市场规则筛选，目前还是研究阶段：严格检验下 RankIC 为负、没有超额收益，所以只看不买。」
- **如果没出结果**：按 §5 兜底切到行情页拉数据或开演示数据模式，别在镜头前反复点。

### 第 5 步（2:35–3:35）跑回测：验证策略
- **位置**：侧边栏「🧪 回测」。
- **操作**：策略下拉从默认的「异动突破」改选「**双均线（ma_cross）**」；标的保持默认 3 只；初始资金 100000；区间保持默认近 3 年（2023-10-26 ~ 2026-10-26）；点「🚀 运行回测」。
- **期望**：约 10–40 秒出结果；8 张 KPI 卡（总收益 ≈ +5.4%、最大回撤 ≈ -7.4%、夏普 ≈ 0.35、胜率 ≈ 26%、交易 ≈ 68 笔，实机为准）；权益曲线 + 回撤曲线；交易明细表；警告区 2–3 条（无基准 / ST 近似 / 最小 1 手调整，属提醒不阻断）。
- **截图**：`shots/04_backtest.png`（KPI + 权益曲线）；可选再拍「交易明细」。
- **口播**：「这些数字只是历史演算，不代表未来；黄色警告是提示我们别过度相信回测。」
- **可选**：点「⬇️ 导出 HTML 报告」会生成单文件报告，可在浏览器打开/归档。

### 第 6 步（3:35–4:20）模拟买入：手动交易
- **位置**：侧边栏「🧾 手动交易」。
- **操作**：标的代码填 `000001.SZ` → 委托价格填 **11.20**（对应 2026-10-23 收盘；若你刚刷新过行情，就照行情页「最新价（收盘）」填）→ 数量填 **100**。
- **A 路径期望（交易时段）**：预检结论「通过」；预计成交金额 1,120.00 元、费用合计约 5 元、成交后单票占比约 1.1%、总仓位约 1.1%。
- **A 路径操作**：勾选「我已了解上述风险，确认执行」→ 点「提交委托」→ 成功提示（成交 100 股 @ 11.20 元）；「今日委托」出现"已成交"。
- **B 路径期望（非交易时段）**：预检结论「不通过 + RK005 非交易时段/非交易日」；提交后「今日委托」出现"已拒绝 RK005"（作为风控演示）。
- **截图**：`shots/05_trade.png`（风控预检面板 + 二次确认）。
- **口播**：「下单前先过风控：金额、费用、仓位、时段逐项检查，手动和自动都绕不过去。」

### 第 7 步（4:20–4:45）看持仓：结果落地
- **位置**：侧边栏「💼 持仓」。
- **A 路径期望**：摘要显示持仓 1 只；明细行 `000001.SZ 平安银行` 数量 100、可用 0、T+1 冻结 100、成本价约 11.20（以实际成交为准）、现价约 11.20、浮动盈亏约 0、仓位占比约 1.1%；现金约 98,874.93 元；资金曲线可能暂时为空（成交后/盘后任务才落库）。
- **B 路径期望**：显示"当前无持仓"空态 + 「去手动交易页买入」按钮；总资产仍 100,000.00。
- **截图**：`shots/06_positions.png`。
- **口播**：「A 股 T+1：今天买的股票，明天才能卖。」

### 第 8 步（4:45–5:20）触发自动化：定时任务
- **位置**：侧边栏「🤖 自动化」。
- **操作**：点「▶️ 启动调度器」→ 勾选「我已了解上述风险，确认执行」→ 点「确认启动」。
- **期望**：调度器状态变「运行中」；3 张任务卡显示执行时间（盘前 08:50 / 盘中 10:00 / 盘后 15:30）与"下次运行"时间。
- **操作**：在「盘前任务」卡片点「立即运行」→ 勾选确认 → 点「确认执行」。
- **期望**：绿色成功提示——非交易日显示"SKIPPED：2026-xx-xx 非交易日，跳过盘前准备"；交易日会实际执行（可能数秒）；卡片"上次结果/上次消息"更新。
- **截图**：`shots/07_automation.png`（调度器状态 + 任务卡 + 成功提示同框）。
- **口播**：「定时任务一键启停；停止不会取消已提交订单；自动下单默认关闭，是安全设计。」

### 第 9 步（可选 5:20–6:00）日志留证：可追溯
- **位置**：侧边栏「📜 日志」。
- **操作**：日志级别选「全部」→ 关键词输入上一步的 trace_id（或 `RK005`）→ 点「🔄 刷新」。
- **期望**：表格出现对应记录（时间/级别/模块/trace_id/消息）；点列头可排序；可导出 CSV。
- **截图**：`shots/08_logs.png`。
- **口播**：「每一次点击、每一笔拒单都能按编号追到日志。」

## 3. 预期数值基线（判断"正不正常"用）

- **账户**：初始总资产 100,000.00 元、可用 100,000.00 元、无持仓、无资金曲线。
- **回测（按第 5 步：双均线 + 近 3 年 + 真实缓存数据）**：总收益 ≈ +5.4%、年化 ≈ +1.9%、最大回撤 ≈ -7.4%、夏普 ≈ 0.35、胜率 ≈ 26%、68 笔、725 个交易日；警告 ≈ 3 条（无基准 / ST 近似 / 不足 1 手调整）。
- **回测（若切到🎬演示数据模式）**：数字与上面不同（同一策略约 +6.7%、回撤 -5.8%、夏普 0.57、130 笔上下），且出现「Mock 数据」警告——**必须在画面与口播里标明"演示数据，非真实行情"**。
- **推荐**：候选 3 只（自选池只有 3 只），属正常；页面会提示研究阶段。
- **筛选**：mock/演示数据下「全市场总数」为 10 只（内置示例池）；真实数据下取决于快照，可能数百~数千只。研究阶段口径（引自 `docs/SCREENER_VALIDATION.md`）：5/10/20 日 RankIC = -0.029 / -0.030 / -0.037，Top 组超额 t = 0.12 / 0.49 / -0.52 → **无可用正向边际**，只能当研究工具。
- **买入（A 路径）**：000001.SZ @11.20 × 100 股 = 1,120.00 元，佣金按最低 5 元，总费用约 5.07 元。
- **自动化**：非交易日盘前任务=SKIPPED；交易日会真实执行（可能拉数据，稍慢）。

## 5. 出问题时的兜底话术

| 现象 | 现场处理 | 一句话过渡 |
|---|---|---|
| 拉数据失败/转圈 | 用已缓存数据继续；或开🎬演示数据模式 | 「数据源临时不可用，系统自动用缓存兜底」 |
| 筛选页无结果/扫描失败 | 先去行情页拉数据或开演示数据模式；仍失败就跳过 | 「全市场扫描需要本地行情，我们先看已有榜单」 |
| 回测提示"数据源未返回行情" | 区间改「近 1 年」或先去行情页拉数据 | 「本地还没这段缓存，缩小范围重跑」 |
| 提交被拒 RK005（B 路径正常） | 顺势讲风控闸门 | 「非交易时段系统直接拦下，这就是保护机制」 |
| 启动调度器失败 | 检查 APScheduler；改用「查看记录」 | 「环境缺依赖，我们看已有运行记录」 |
| 页面白屏/显示怪 | 侧边栏「🔄 清缓存并刷新」 | 「刷新一下缓存即可」 |

## 6. 研究阶段口径（录制时必须说到）

- **现状**：推荐页（两个 Tab）已修复可正常出列表；筛选页当前用「原型规则，验证中」兜底（正式筛选服务尚未接入）。两者都不是买入建议。
- **必须说的数字**（引自 `docs/SCREENER_VALIDATION.md` §2/§4）：5/10/20 日 RankIC = -0.029 / -0.030 / -0.037；Top 组相对全市场超额 t = 0.12 / 0.49 / -0.52 → 没有可用的正向边际。
- **口播模板**：「榜单和筛选器都还是研究阶段，规则没通过样本外验证，我们只用来观察，不据此买入。」
- **画面要求**：第 3、4 步必须让「研究阶段提示 / 原型规则，验证中 / 合规提示」至少一张警示卡入画。
- **兜底**：若筛选页拉不到数据，跳过第 4 步，改用推荐页；不要剪掉警示卡后当作"有效推荐"展示。

- 节奏：每次点击后停 1 秒再移动鼠标；窗口不要切换；不要露出浏览器书签/隐私标签。
- 命名：`quantdesk_demo_5min_20261026.mp4`；截图统一放工作区的 `shots/`（已有截图目录，与 `quantdesk_m0.png` 同级）。
- 收尾：录制结束后先导出 mp4，再关闭 `start.bat` 黑窗口（关窗＝停止服务）。
