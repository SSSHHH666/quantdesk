# QuantDesk 用户手册（写给不懂代码的你）

> 版本 v1.0 · 2026-10-26 · 适用：本机 Windows 单用户版
> 读法：先看 §1–§4（5 分钟能跑起来），用的时候再查 §6 页面说明和 §8 常见问题。
> 一句话：**这是一个本地运行的模拟炒股工作台——它帮你拉数据、出候选、跑回测、模拟下单、定时干活；但它不替你赚钱，也不保证赚钱。**

## 1. 这是什么？

- 一个装在你自己电脑上的「量化交易工作台」：双击一个文件启动，用浏览器点按钮操作。
- 它把「拉行情 → 策略出信号 → 风控把关 → 回测验证 → 模拟盘下单 → 定时任务 → 看板与日志」串成一条链。
- 全部中文界面；不需要写代码；不联网也能用内置示例数据看界面（但回测/推荐要真实数据才准）。

**适合**：想自己研究 A 股、验证想法、练手模拟交易的个人用户。
**不适合**：想直接挂真实资金自动赚钱、想要"保证收益"、想多人同时用。

## 2. 能做什么？

- **看行情**：K 线、均线、成交量、RSI/MACD 副图、最新价与涨跌幅。
- **看候选**：今日推荐页给两份榜单（全市场短线雷达 / 自选池长期精选）；全市场筛选页按流动性+规则筛短线候选。两条路径都带推荐理由与「研究阶段」标注。
- **跑回测**：选策略和区间，几秒到几十秒出一份报告（收益、回撤、夏普、胜率、交易明细），可导出 HTML。
- **模拟下单**：手动买/卖，下单前先看"风控预检"（金额、费用、仓位、结论），成交后看持仓与资金。
- **自动干活**：定时任务（盘前/盘中/盘后）可启停、可立即运行，运行结果进日志，可追溯。
- **留痕**：所有下单、任务、审计都有日志；页面出错会给中文提示和编号（trace_id）。

## 3. 不能做什么？（请务必读完）

- **不承诺收益，也不构成投资建议。** 回测和榜单只说明"过去这样算出来是这样"，不代表未来。
- **短线模型仍在研究阶段。** 实测样本外命中率不足，目前榜单用的是规则打分，仅作研究参考，**不要据此实盘**。
- **不能接真实资金。** 当前只有模拟盘（PaperBroker）和两个空的实盘适配骨架；真实下单需要你自备券商柜台（QMT 等），本版不提供。
- 不做 L2 逐笔行情、不做多用户/权限、不做云部署和手机 App。
- A 股数据来自公开接口，可能缺失、延迟或改版；**非交易时段不能下单**（这是风控保护，不是故障）。

## 4. 三分钟上手

| 步骤 | 你做什么 | 你会看到什么 |
|---|---|---|
| 1 | 打开 `quantdesk\scripts` 文件夹，**双击 `start.bat`**，黑窗口别关 | 窗口打印 `[启动] 正在启动 QuantDesk...`；关窗口＝停止服务 |
| 2 | 浏览器打开 **http://localhost:8501** | 左侧导航 12 个页面，底部写「模拟盘 · 实盘未接入」 |
| 3 | 左侧点「📈 行情」→ 选 `600519.SH` → 区间「近 1 年」→ 点「🔄 拉取/刷新数据」 | 出现日 K 线 + MA5/10/20/60 + 成交量；下方显示最新价、涨跌幅 |
| 4 | 左侧点「🎯 今日推荐」→ 切换「全市场短线雷达 / 自选池长期精选」 | 出现候选列表与推荐理由；两个榜单都标「研究阶段」，只作研究参考 |
| 5 | 左侧点「🧪 回测」→ 策略选「双均线」→ 区间保持「近 3 年」→ 点「🚀 运行回测」 | KPI 卡片、权益曲线、交易明细；可点「⬇️ 导出 HTML 报告」 |
| 6 | 左侧点「🧾 手动交易」→ 填代码 `000001.SZ`、价格（照行情页最新价，例 11.20）、数量 100 | 「风控预检」显示金额/费用/仓位/结论；勾选确认后提交（**只有交易日交易时段会成交**） |

> 第一次用建议先按顺序点一遍「总览」页的「👋 新用户上手指引」四个按钮，它会带你跳转。

## 5. 先认识界面（侧边栏）

- **顶部**：产品名、版本号、模式「模拟盘 · 实盘未接入」。
- **交易账户**：当前只有 1 个模拟账户（初始资金 10 万），多账户是以后的事。
- **🎬 演示数据模式（mock）**：打开后用内置示例数据（2021–2026），不联网也能看完整界面；页面会反复提示"不是真实行情"。
- **状态灯 4 个**：数据源 / 调度器 / 数据库 / 日志。绿色正常；黄色要先处理（数据库没就绪时下单、回测都会失败）。
- **功能导航（12 页）**：总览 → 行情 → 手动交易 → 今日推荐 → 全市场筛选 → 自选池 → 策略 → 回测 → 持仓 → 自动化 → 设置 → 日志（逐个说明见 §6）。
- **🔄 清缓存并刷新**：页面显示怪了、改了配置后，先点它。
- **黄色提示条**：出现"离线模式"或"演示数据"时，说明当前看到的可能不是真实行情。

## 6. 12 个页面逐个看

### 6.1 总览 🏠
- **干什么**：一屏看账户与系统状态，新用户从这里开始。
- **看什么**：顶部 4 个状态灯；6 个 KPI（总资产/当日盈亏/累计收益率/可用资金/持仓市值/总仓位）；权益曲线（含回撤）；持仓 Top5；最近告警。
- **怎么操作**：点「👋 新用户上手指引」的 ① 拉数据 ② 看推荐 ③ 跑回测 ④ 模拟下单，会跳到对应页；点「🔄 刷新总览」重算。
- **常见提示**：「今日信号与订单」区显示"功能开发中"＝设计内空白；「暂无资金曲线」＝还没成交或还没跑盘后任务；「最近无告警」＝一切正常。

### 6.2 行情 📈
- **干什么**：看单只股票的 K 线与指标，是数据入口。
- **看什么**：K 线 + MA5/10/20/60 + 成交量；副图可切 成交量/RSI/MACD；右侧最新价（收盘）、涨跌幅、成交额；数据来源与数据点数量。
- **怎么操作**：搜索框输代码或名称（如 600519）→ 选区间与复权方式 → 点「🔄 拉取/刷新数据」把行情存到本地 → 点「⭐ 加入自选」；下方「去回测 →」「去下单 →」会带上当前股票。
- **常见提示**：「该区间没有可用行情」＝先点拉取/刷新；黄色卡片「数据源已降级（离线演示）」＝在用示例数据，别当真实行情。

### 6.3 手动交易 🧾
- **干什么**：手动下模拟单，下单前自动做风控预检。
- **看什么**：顶部账户概览（总资产/可用/冻结/持仓市值）；中间委托表单；**风控预检面板**（预计金额、费用合计、成交后单票占比、成交后总仓位、风控结论与原因码、可买/可卖数量）；底部「今日委托」。
- **怎么操作**：填代码 → 填价格（照行情页「最新价（收盘）」，或 ±0.01 微调）→ 填数量（A 股 100 股整数倍）→ 看预检通过 → 勾选二次确认 → 点「提交委托」。
- **常见提示**：「风控结论：不通过 + RK005」＝现在不是交易时段；「RK016」＝今天买的今天不能卖（T+1）；「RK012」＝金额太小（低于 1000 元）或太大（超过总资产 10%）。

### 6.4 今日推荐 🎯
- **干什么**：给两份候选榜单，研究用，不会自动下单。
- **看什么**：两个页签「全市场短线雷达」「自选池长期精选」；每行有代码、名称、现价、涨跌幅、成交量比、突破幅度、推荐理由（附得分拆解）、风险提示；顶部有候选/入选/策略/数据源状态条。
- **怎么操作**：点「🔄 刷新推荐」重算；点行尾「加入自选」把股票放进自选池（短线雷达→近期分组，长期精选→远期分组）；「⭐ 去自选池」跳转管理。
- **常见提示**：短线雷达顶部有「⚠️ 研究阶段提示」，请认真读；「自选池为空」＝先去自选池加 3–10 只股票。**两个榜单都标「研究阶段」，只作研究参考，不能当买入建议。**

### 6.5 全市场筛选 🔎
- **干什么**：按流动性（成交额）先筛前 N 只，再用规则给短线候选打分，给研究用。
- **看什么**：顶部「合规提示」+「原型规则，验证中」；状态条（全市场总数/流动性过滤后/本次扫描/数据时间/规则）；结果表（代码/名称/现价/涨跌幅/成交额/得分/入选理由/风险标记）。
- **怎么操作**：调「流动性前 N」（默认 300）、「Top N」（默认 25）、是否「剔除过热（涨幅≥9.5%）」→ 点「🔄 刷新扫描」；行尾「加入自选」只写自选池；可导出 CSV。
- **常见提示**：看到「研究阶段」「原型规则，验证中」＝规则还没通过有效性验证，**不是买入信号**；「本次筛选没有结果」＝先去行情页拉数据，或开演示数据模式。

### 6.6 自选池 ⭐
- **干什么**：管你关注的股票，它是拉数据、策略、自动化的默认股票池。
- **看什么**：总数与分组统计；列表（代码/名称/分组/最新价/涨跌幅/成交额/备注/加入时间）。
- **怎么操作**：顶部选「全部/近期/远期」；「➕ 添加标的」逐个加；「📋 批量导入」每行一个代码（支持 `600519`、`600519.SH`、`600519 贵州茅台`，`#` 开头是注释）；「🔄 刷新行情」更新价格；可导出 CSV、编辑、删除、清空分组。
- **常见提示**：重复代码不会重复添加；改完立刻生效，不需要保存按钮。

### 6.7 策略 🧠
- **干什么**：看系统内置哪些策略、每个策略要什么参数。
- **看什么**：策略列表（名称/说明/参数个数/预热 Bar 数）；选中后出现中文参数表单与参数说明表。
- **怎么操作**：选策略 → 按提示调参数（如快线周期必须小于慢线周期）→ 点「🧪 去回测（带当前参数）」直接带着参数去回测页。
- **常见提示**：「策略实例管理功能开发中」＝自动交易的实例功能还没接，属设计内空白；「策略参数不合法」按红字改即可。

### 6.8 回测 🧪
- **干什么**：用历史数据验证策略，回答"如果过去这样做，结果会怎样"。
- **看什么**：参数区（策略/标的/初始资金/开始结束日期/高级参数里的滑点与基准）；运行后出现 8 个 KPI（总收益、年化、最大回撤、夏普、胜率、盈亏比、交易次数、波动率）、权益曲线 vs 基准、回撤曲线、交易明细表、可信度与警告。
- **怎么操作**：选策略与标的（默认自选池 3 只）→ 保持默认资金 10 万与近 3 年 → 点「🚀 运行回测」→ 点「⬇️ 导出 HTML 报告」存档。
- **常见提示**：黄色警告（如"无基准""交易次数少""ST 近似"）是提醒不是报错；「本次回测没有产生任何成交」＝该区间没信号或数据不足。

### 6.9 持仓 💼
- **干什么**：看模拟账户里到底有什么。
- **看什么**：账户摘要（总资产/可用资金/持仓市值/累计收益率/总仓位）；持仓明细（数量、可用、T+1 冻结、成本价、现价、市值、浮动盈亏、盈亏%、仓位占比）；资金曲线；资产配置饼图；导出 CSV。
- **怎么操作**：「🔄 刷新」；「🧹 一键清仓」会逐笔卖出并再过一次风控（T+1 当天买入的卖不掉，属正常）；「⚙️ 账户重置」目前是"功能开发中"。
- **常见提示**：「当前无持仓」＝去手动交易页买一笔；「最近成交」区显示接口待接入＝设计内空白。

### 6.10 自动化 🤖
- **干什么**：让系统按时间自动跑任务（盘前准备 08:50 / 盘中扫描 10:00 / 盘后总结 15:30）。
- **看什么**：顶部「自动化开关：已关闭（默认，安全）」；调度器总开关；3 张任务卡片（执行时间、下次运行、上次结果、上次消息）；「今日管线统计」；最近运行记录。
- **怎么操作**：点「▶️ 启动调度器」→ 二次确认 → 状态变「运行中」；点某任务的「立即运行」可手工触发；「查看记录」看该任务最近日志；停止不会取消已提交订单。
- **常见提示**：非交易日任务显示 `SKIPPED`（跳过，不是失败）；「今日管线统计」显示"功能开发中"＝设计内空白；自动**下单**默认关闭，要开需改配置文件（见 §8.7）。

### 6.11 设置 ⚙️
- **干什么**：看数据源、风控参数、通知、备份、环境、版本与免责声明。
- **看什么**：6 个页签——数据源（provider、历史年限、自选池）、风控（8 个参数与对应拒单码 RK004/007/008/009/010/012/013）、通知（桌面/邮件/Webhook）、存储与备份（备份文件列表、数据库大小）、环境（依赖是否齐全、TA-Lib/ccxt 状态、日志级别）、关于（版本、模式、许可证、免责）。
- **怎么操作**：目前以**只读查看**为主；「🔌 连通性测试」「发送测试通知」「立即备份」等按钮还没接好，点了只给中文提示；备份请用脚本（见 §8.6）。
- **常见提示**：「保存类按钮灰显/提示接口待接入」＝本版设计如此；要改参数请改 `config.yaml` 后点侧边栏「🔄 清缓存并刷新」（见 §8.9）。

### 6.12 日志 📜
- **干什么**：查证据链——一次下单/一次任务到底发生了什么。
- **看什么**：运行日志表（时间/级别/模块/trace_id/消息）；可切「审计流水 / 数据校验报告 / 通知记录」三个页签。
- **怎么操作**：选级别、输关键词（如 `RK005`、`600519.SH`、trace_id）→「🔄 刷新」→ 可导出 CSV；点击列头可排序。
- **常见提示**：后三个页签显示"功能开发中"＝设计内空白；「暂无运行日志」＝还没跑过任务或回测，先跑一次即可生成。

## 7. 术语小抄

| 你会看到 | 意思（一句话） |
|---|---|
| T+1 | 今天买的股票，最快明天才能卖 |
| 涨跌停 | 一天最多涨/跌到限定幅度，到顶了买不进/卖不出 |
| 复权 | 把分红送股造成的价格跳空抹平，看"真实涨跌"用前复权，回测默认用不复权真实价 |
| 回撤 | 从最高点跌下来的幅度，越深越难受 |
| 夏普 / 胜率 / 盈亏比 | 赚的钱与波动之比 / 赚钱次数占比 / 平均赚的是平均亏的几倍（样本短时都别当真） |
| 滑点 / 仓位 | 实际成交与期望价的损耗 / 花在股票上的钱占总资产多少 |
| RankIC | 打分与未来收益的排名相关性；接近 0 或为负＝排序没有预测力 |
| 模拟盘 | 假钱真练手，不会动你的银行账户 |
| Mock/演示数据 | 系统内置的假行情，只为看界面，不能当真实数据 |
| RK / DQ / RQ | 风控拒单码 / 数据质量码 / 回测警告码，用来定位原因 |
| 样本外 / walk-forward | 用没参与调参的后期数据验证，防止"回测好看、实盘亏钱" |
| UBA | User Bears All：赚了亏了都是你自己的决定与风险，系统只提供工具 |

> 完整版（含公式与更多词）看 [`GLOSSARY.md`](GLOSSARY.md)。

## 8. 常见问题

### 8.1 数据拉不到 / 点「拉取/刷新数据」没反应？
- 先看侧边栏状态灯：数据库是否"就绪"；再看行情页错误卡上的建议。
- 网络问题：akshare 偶尔被限流或改版，等几分钟重试；公司网络/代理可能拦截，先试试浏览器能否访问公开行情站。
- 批量补数据（可选，命令行）：`.venv\Scripts\python.exe scripts\fetch_data.py --watchlist --years 5`。
- 完全没网也能演示界面：打开侧边栏「🎬 演示数据模式」。

### 8.2 界面显示"演示数据 / 离线模式"，正常吗？
- 三种来源：① 你打开了侧边栏「🎬 演示数据模式」；② 数据源连不上，系统自动降级 mock；③ 部分股票单只降级（行情页会标"部分行情来自 mock 兜底"）。
- 看到黄色提示条说明**当前不是真实行情**：用于看布局可以，用于研究/回测结论不行。
- 回到真实数据：关掉演示模式 → 到行情页点「拉取/刷新数据」；仍不行就查网络或数据源配置。
- 如果数据库里曾混入假数据，可先干跑检查：`.venv\Scripts\python.exe scripts\purge_mock_cache.py --dry-run`（只读）；确认后再执行清理并回填真实数据。

### 8.3 为什么现在不能下单？（提示休市 / RK005）
- 系统只允许 A 股连续竞价时段下单：**交易日 09:30–11:30、13:00–15:00**；周末、节假日、晚上都不行。
- 提示原文："非交易时段/非交易日：当前处于休市状态，禁止委托（RK005）"——这是**设计保护**，不是 bug。
- 想在非交易时段体验流程，可以看「风控预检」面板（只读、不落单）；或到回测页看历史交易明细。

### 8.4 风控拒单了，怎么看原因？
- 先看手动交易页「风控预检」：有"风控结论 / 原因码 / 规则明细"三块，展开"风控规则明细（为什么通过/被拒）"能看到 10 步检查逐条结果。
- 每条拒单都有一张中文错误卡（原因码 + 建议），点卡片里的「查看日志」会跳到日志页并按 trace_id 过滤。
- 最常遇到的 8 个码：RK005 非交易时段 / RK007 单票超 20% / RK008 总仓位超 80% / RK010 价格偏离超 2% / RK012 单笔金额不合规 / RK014 可用资金不足 / RK016 今天买的不能卖 / RK017 数量不是 100 股整数倍。
- 全部 20 个码见 [`SPEC.md`](SPEC.md) §9.2；页面上也内嵌了中文说明。

### 8.5 回测页提示"数据源未返回行情 / 请先拉取并缓存数据"？
- 说明该区间本地没有缓存行情，且数据源直连也取不到（网络/接口临时不可用）。
- 处理：到行情页对相关股票点「拉取/刷新数据」；或缩小/前移回测区间后重试。

### 8.6 如何备份和恢复？
- 真正的数据只有一份：`runtime\quantdesk.db`（还有 `-wal`/`-shm` 同族文件，别单独删）。
- 备份（推荐，先关应用）：`.venv\Scripts\python.exe scripts\backup_db.py`；备份文件在 `runtime\backups\`，默认保留最近 7 份。
- 恢复：先停应用，再 `.venv\Scripts\python.exe scripts\restore_db.py --list` 看备份 → `... restore_db.py 备份文件 --yes`（恢复前会自动先备份当前库）。
- 设置页「存储与备份」能看到备份文件列表，但按钮还没接好；手工复制 `quantdesk.db` 也等价（务必先停应用）。

### 8.7 如何开启自动化（定时任务）？
- 第一步（界面内）：自动化页「▶️ 启动调度器」→ 二次确认 → 状态变"运行中"；任务到点自动跑，也可「立即运行」。
- 第二步（要真正自动下单才需要）：打开 `quantdesk\config.yaml`，把 `automation.enabled` 和 `risk.allow_auto_orders` 改成 `true`，保存后点侧边栏「🔄 清缓存并刷新」。**默认都是 false，是安全设计。**
- 停止：自动化页「⏹️ 停止调度器」；或直接关掉黑窗口（调度器随程序退出）。

### 8.8 双击 start.bat 打不开 / 8501 端口被占用？
- 窗口一闪而过：从命令行进 `quantdesk` 目录执行 `scripts\start.bat`，就能看到完整报错；按提示装依赖（`scripts\check_env.py` 会列缺失清单）。
- 端口占用：`netstat -ano | findstr :8501` 找 PID → `taskkill /PID 编号 /F`；或换端口启动（见 [`RUNBOOK.md`](RUNBOOK.md) §2.2）。
- 页面白屏/报错：侧边栏「🔄 清缓存并刷新」；仍不行看日志页或 `runtime\logs\app-*.log`。

### 8.9 想改风控参数、自选池默认股票、自动化开关？
- 设置页目前是只读的，改配置请编辑 `quantdesk\config.yaml`（风控在 `risk:` 段、自选池在 `data.universe`、自动化在 `automation:`），保存后点「🔄 清缓存并刷新」。
- 自选池增删改请用「⭐ 自选池」页面（立即生效，写入数据库）。
- 改坏了别慌：重新拉取一份 config.yaml 覆盖即可；环境类问题看 [`RUNBOOK.md`](RUNBOOK.md)。

### 8.10 「全市场筛选」和「今日推荐」有什么区别？都是研究阶段吗？
- 区别：前者是"全市场按流动性+规则打分"筛短线候选；后者是「全市场短线雷达 / 自选池长期精选」两份榜单。
- 共同点：**都是研究阶段**。筛选器实测 RankIC 为负、Top 组相对全市场无超额；短线模型 OOS 命中率不足——页面会明确标注，别当买入建议。
- 想看证据：见 [`SCREENER_VALIDATION.md`](SCREENER_VALIDATION.md)（§2 RankIC、§6 结论）与页面顶部的「研究阶段提示」。

## 9. 当前版本的已知问题

- **全市场筛选 / 短线雷达仍是研究阶段**：筛选页目前由「原型规则，验证中」兜底（正式筛选服务尚未接入），且 `docs/SCREENER_VALIDATION.md` 的严格检验显示 RankIC 为负、Top 组无超额 → 只能当研究工具，不能据此下单。
- **设置页保存类操作未接入**：风控参数、通知、备份、恢复默认等按钮点了只会提示"接口待接入"；改配置请编辑 `config.yaml`（§8.9）。
- **以下区域显示"功能开发中"，属设计内空白**：今日信号与订单、策略实例管理、今日管线统计与测试通知、最近成交明细与撤单、账户重置、审计/数据校验/通知查询、回测历史对比。
- **回测结果暂不落库**：每次运行是内存计算，页面刷新后本次结果消失；想留存请导出 HTML 报告。
- 以上问题不会影响「行情 / 自选池 / 回测 / 手动交易 / 持仓 / 自动化 / 日志」的核心流程。

## 10. 安全与合规

- **模拟盘 vs 实盘**：当前只有模拟盘（假钱），实盘适配层是空骨架；接入真实券商需要你自备柜台与账户，本版不提供、也不做任何真实下单。
- **密钥不落日志**：密码/Token 只从环境变量读取（`QD_` 前缀，如 `QD_SMTP_PASSWORD`），不写进配置文件、数据库或日志；日志中的敏感字段会自动脱敏。
- **用户自担风险（UBA）**：本系统只提供研究工具与信号，不承诺收益、不代客理财、不构成投资建议；所有买卖决定与盈亏由你自己承担。页面固定的"个人非商业研究用途 · 不构成投资建议"即此意。
- **推荐/筛选不会自动下单**：榜单与筛选结果只能「加入自选池」，没有「一键买入」入口；自动化下单默认关闭，需你显式打开配置（§8.7）。
- **数据合规**：行情来自公开数据接口，仅限个人研究，请遵守上游条款，不要高频/并发抓取；数据可能延迟、缺失或改版。
- **本地与隐私**：程序只监听本机 localhost，不上传你的持仓、账户或日志；卸载/迁移前先备份 `runtime\quantdesk.db`。
