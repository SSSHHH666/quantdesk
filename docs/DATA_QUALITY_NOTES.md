## 0. 一句话结论（先看这 6 条）

1. **撮合一律用不复权价**（`adjust=''`），复权只用于算信号/收益；混用会算出假收益。
2. **不复权价在除权除息日会"假暴跌"**——本批实测最大 -31.77%，直接当异常波动或止损会误伤。
3. **`volume` 单位是股、`amount` 单位是元**（实测 `amount/volume/close ≈ 1.001`）；别按"手"再乘 100。
4. **换手率是小数（0.46 = 0.46%），涨跌幅是百分数（1.21 = 1.21%）**——同一份快照里两种口径混着。
5. **停牌日没有 bar，不要补造**；特征可前向填充，撮合必须跳过。
6. **同一个标的存在多个 `source` 时禁止直接拼接**（历史上 mock 混入曾造出 246% 假收益）。

## 2. 复权：三种口径与公式（最容易算错的地方）

### 2.1 口径定义

| 口径 | 含义 | 用途 |
|---|---|---|
| `none` 不复权 | 交易所原始成交价 | **撮合/成交价/涨跌停判断**（唯一正确口径） |
| `qfq` 前复权 | 以**最新**价格为基准回溯，历史价被调低 | 画图、给人看 |
| `hfq` 后复权 | 以**上市首日**为基准，价格随分红送股累积放大 | 计算长期收益、因子 |

### 2.2 因子公式（本批数据实测口径）

新浪 `stock_zh_a_daily(adjust='qfq-factor')` / `('hfq-factor')` 返回**离散的除权日因子序列**，需按日期 asof 向后合并：

```text
前复权价 = 不复权价 ÷ qfq_factor          （等价：不复权价 = 前复权价 × qfq_factor）
后复权价 = 不复权价 × hfq_factor          （等价：hfq_factor ≥ 1，上市首日 = 1）
```

**实测验证（600519.SH，qfq_factor）**：

| 日期 | 不复权收盘 | qfq_factor | 前复权收盘 |
|---|---:|---:|---:|
| 2019-07-01 | 91.10 | 2.5940873959 | 35.12 |
| 2019-07-02 | 67.97 | 1.8411223083 | 36.92 |

→ 当天不复权价"跌 -25.39%"，但**前复权价实际涨 +5.1%**：这就是除权，不是下跌。

**后复权因子实测验证（本批 CSV 使用的口径）**：603259.SH 在 2019-07-02 除权，`hfq_factor` 从 `1.0` 跳到 `1.408971`：

| 日期 | 不复权收盘 | hfq_factor | 后复权收盘（= 不复权 × 因子） |
|---|---:|---:|---:|
| 2019-07-01 | 91.10 | 1.000000 | 91.10 |
| 2019-07-02 | 67.97 | 1.408971 | 95.77 |
| 2019-07-03 | 66.75 | 1.408971 | 94.05 |

→ 后复权序列在除权日**连续**（91.10 → 95.77），可直接算收益；不复权序列出现 -25.39% 的假跳空。

### 2.3 实测证据：不复权价的"除权日假暴跌"

对 `runtime/short_term/bars_50.csv`（50 只、2019-01-01~2026-10-23）逐日计算涨跌幅，`|涨跌| > 20%` 的共 **69 行**，按板块拆分核对后结论如下（**不要**简单当成"脏数据"）：

| 板块 | 行数 | 与除权日对齐 | 性质 |
|---|---:|---:|---|
| 沪深主板（限 ±10%） | **12** | **12 / 12** | 主板不可能单日跌超 20% → **全部是除权日的假跳空** |
| 创业板/科创板（限 ±20%） | 57 | 23 | 其余 34 行是**真实行情波动**（±20% 合法；涨跌停价四舍五入会出现 20.01%） |

主板 12 行全部为除权（不复权价与后复权价的对照如下，`hfq_factor` 在除权日跳变）：

| 标的 | 日期 | 不复权涨跌幅 | hfq_factor 变化 | 后复权收盘（除权前→后） |
|---|---|---:|---|---|
| 603259.SH 药明康德 | 2019-07-02 | **-25.39%** | 1.000000 → 1.408971 | 91.10 → 95.77（**+5.1%**） |
| 603259.SH 药明康德 | 2020-06-04 | **-27.76%** | 1.408971 → 1.978476 | 158.76 → 161.05 |
| 001309.SZ 德明利 | 2025-07-10 | **-31.77%** | 1.825091 → 2.561437 | 222.30 → 212.86 |
| 603986.SH 兆易创新 | 2021-05-21 | **-29.98%** | 3.959483 → 5.561178 | 688.79 → 677.35（**-1.7%**） |

> 小结：主板 12 行的不复权跌幅落在 **-20.67% ~ -31.77%**；后复权序列在除权日连续，可用收益。

**避坑做法**：

- 用不复权价算"日收益/波动/止损"之前，**先按 `adj_factor` 变化点把除权日标记出来**（`factor` 当日变化 → 当日为除权日）；
- 或者直接用前复权价算收益、用不复权价撮合——两者**绝不混在同一笔计算里**；
- 异常涨跌过滤器（如 >20% 视为脏数据）必须**先剔除除权日**，否则会误删真实行情。

### 2.4 模型选择建议

- **撮合**：`none`（不复权）。
- **信号/收益/因子**：`qfq` 或 `hfq` 任选其一并**全程一致**；跨标的比较用 `qfq`（以最新价为基准，横向可比）。
- **不要用"前复权价直接当成交价"**：前复权价与当日真实成交价不同，会造成"买入价失真"。

## 3. 停牌：缺 bar 是正常现象，不是丢数

**现象**：某标的某天没有 bar（`daily_bars` 无该行 / CSV 无该行），尤其在重大资产重组、ST 前后。

**正确处理**：

| 场景 | 做法 |
|---|---|
| 特征计算 | 允许按交易日历做**前向填充**（用最后有效值），并同时给出"停牌天数"特征 |
| 撮合/成交 | **必须跳过**：停牌日不可成交，不能假设"按昨收成交" |
| 收益计算 | 停牌期间收益为 0（价格不变），复牌当日按真实成交价计算 |
| 数据校验 | 停牌日**不得补造 bar**（补出来的假成交量会被当成真实成交） |

**识别方法**：与交易日历对比缺日；快照里 `成交额 = 0` 或 `最新价` 为空也是停牌/未开盘信号（本批快照含 1 只此类，已剔除）。

**关键区分：缺日 = 停牌，还是数据源有洞？** 必须用**第二个数据源交叉验证**，否则可能把"数据缺失"当成停牌（模型会永久少样本）或把"停牌"当成缺失（补造出假价格）。

本批实测（`runtime/exports/universe_coverage.md` §4.1）：14 只标的存在缺口，抽 3 例用**腾讯备源**核对：

| 标的 | 新浪缺的日期 | 腾讯同期返回 | 结论 |
|---|---|---|---|
| 002185.SZ 华天科技 | 2019-07-03 ~ 07-08 | 只有 2019-07-02 的 bar | 真实停牌 |
| 600176.SH 中国巨石 | 2020-12-02 ~ 12-08 | 只有 2020-12-01 的 bar | 真实停牌 |
| 600150.SH 中国船舶 | 2019-03-28 ~ 04-04 | 只有 03-27 与 04-08 的 bar | 真实停牌（重组） |

→ 两个独立源都缺 = 停牌；只有一处缺 = 数据洞，需回源补。

## 4. 除权除息：名称前缀 + 事件日

1. **新浪快照的名称带瞬时前缀，且会被截断**：实测 `sh688008` → `XD澜起科`（本名「澜起科技」）、`sh600150` → `XD中国船`（本名「中国船舶」）。
   前缀含义：`XD` 除息日、`XR` 除权日、`DR` 除权除息、`N` 新股、`C` 上市初期；**且 `XD`+4 字会把名称截断**。
   → 名称**不要用快照**，要用交易所官方列表校正（`stock_info_sh_name_code` 主板/科创板 + `stock_info_sz_name_code` A股列表，
   实测一次拉 5224 条、耗时 <1s）；本批 `data/universe_50.json` 的名称已按官方列表校正。
2. **`adjust_events` 表**（分红送配）与 `qfq/hfq_factor` 跳变点应能对上；对不上说明事件缺失，**不要自己算比例补**。
3. 复权因子缺失时：**留空 + 标记 DQ**，不要用相邻标的值或"假设 1.0"填充（1.0 意味着"没除过权"，多数老股是错的）。

## 5. 涨跌停：判断"能不能成交"，不要用收盘价猜

| 板块 | 涨跌幅限制 | 备注 |
|---|---|---|
| 沪深主板 | ±10% | ST/*ST 为 ±5% |
| 创业板（300/301） | ±20% | 注册制 |
| 科创板（688/689） | ±20% | 注册制 |
| 北交所（8xxxxx/920xxx） | ±30% | **本批股票池已排除** |

**坑点**：

1. **涨停不可买、跌停不可卖**（回测口径）：当日 `最高价 == 涨停价` 且 `收盘价 == 涨停价` 时，视为买不进；反之跌停卖不出。
2. **不要用"涨跌幅 ≥ 9.9%"近似涨停**：主板 10%、ST 5%、创业/科创 20%，一个阈值套全市场会大量误判。
3. **涨停价 = 前收盘 × (1 + 幅度)，按 0.01 元四舍五入**；前收盘要用**不复权**的前一交易日收盘。
4. **新股上市初期可能无涨跌幅限制**（注册制新股前若干交易日），这类样本建议在短线模型中直接排除或单独处理，不要按 ±20% 硬套。
5. 除权日的前收盘要用**除权后的参考价**，否则涨停价算错——这也是先标记除权日的原因（§2.3）。

## 6. 成交量 / 成交额单位

**实测结论**（`bars_50.csv` 前 2000 行）：`amount / volume / close` 中位数 = **1.0012 ≈ 1**

| 字段 | 单位 | 证据 |
|---|---|---|
| `volume` | **股**（不是手） | 上式计算 ≈1 才成立；若按手需乘 100，比值会变 100 |
| `amount` | **元** | 同上 |
| 某日成交额（元） ÷ 流通市值 = 换手率 | 校验一致 | 见 §7 |

**坑点**：

- 新浪/腾讯都是"股"；**部分东财接口是"手"**，混用会差 100 倍。
- 竞价撮合/盘口常见"手"（1 手 = 100 股），换算在**展示层**做，数据层统一用股。
- 科创板 200 股起、主板 100 股，最小单位差异不影响 volume 单位（仍是股）。

## 7. 换手率：小数 vs 百分比

| 来源 | 字段 | 口径 | 示例 |
|---|---|---|---|
| 新浪日线 `stock_zh_a_daily` | `turnover` | **小数** | 0.004615 = **0.46%** |
| 新浪全市场快照 `stock_zh_a_spot`（`data/a_spot.csv`） | `涨跌幅` | **百分数** | 1.21 = **1.21%** |
| 东财快照（不可用） | `换手率` | 百分数 | 1.21 = 1.21% |

**避坑**：拿到 `turnover`/`换手率` 先看量级——`> 1` 一定是百分数，`< 1` 要警惕（0.5 可能是 0.5% 也可能是 50%）。
本批 `bars_50.csv` 的 `volume/amount` 可由 `amount / 流通市值` 自行算换手率，**不依赖该字段**。

## 8. 价格精度与四舍五入

- A 股最小价格变动 **0.01 元**；不复权价应为两位小数，**出现 3 位以上小数说明被复权处理过**（前/后复权价可多位小数）。
- 费用/金额计算建议**以"分"为单位做整数运算**，最后再转元，避免浮点累计误差（本项目回测/撮合已在费用模型里这么做）。
- 因子的 `adj_factor` 保留 8–10 位小数即可，过度截断会在长周期累积出偏差。

## 9. 混源（假数据）污染：最危险的一类

**历史事故（已修复，必须引以为戒）**：早期版本在 akshare 失败时用 Mock 假数据兜底并写入 `daily_bars`，同一标的同时存在 mock 行（262 行）与真实行（436 行），跨区间拼接后回测出 **246% 假收益**。

**现行铁律**（`data/cache.py` 已强制）：

1. `source='mock'` 数据**不得写入** `daily_bars`（`UpdateReport.mock_blocked`）；
2. 同一标的同一区间出现**多个 source** → `BarCache.load` **fail-closed 抛错**，不做拼接；
3. 清理工具：`scripts/purge_mock_cache.py`（幂等，支持 `--dry-run`）。

**给模型团队的检查**：取数后先跑 `SELECT symbol, COUNT(DISTINCT source) FROM daily_bars GROUP BY symbol`，
任何 `> 1` 的标的都要停下来核对，不要"先跑起来再说"。

## 10. 时间与交易日历

1. **当日 bar 的完整性**：15:00 收盘后日线才定稿；**15:30 之前抓取当日 bar 可能是不完整/缺失的**（本批数据在 21:31 抓取，已含 2026-10-26 当日 bar，因此按约定截断到 `2026-10-23`）。
2. **日期是交易日**：没有周末/节假日 bar；用交易日历对齐，不要用自然日做 `resample` 后再假设每天都交易。
3. **时区**：统一用 `Asia/Shanghai` 的**本地日期**，不要用 UTC 时间戳切日（会错一天）。
4. 快照 `data/a_spot.csv` 的 `时间戳` 字段是 `15:30:00`（收盘后统一快照），不是逐笔时间。

## 11. 取数后的质量检查清单（每次必跑）

| # | 检查 | 通过标准 |
|---|---|---|
| 1 | 主键唯一 `(date, symbol)` | 重复 = 0 |
| 2 | 价格为正 | `open/high/low/close > 0` |
| 3 | `high ≥ max(open, close)`、`low ≤ min(open, close)` | 违反 = 0 |
| 4 | `volume ≥ 0`、`amount ≥ 0` | 负值 = 0（成交额=0 可能是停牌，见 §3） |
| 5 | 单标的 source 唯一 | 混源标的 = 0 |
| 6 | 缺日 = 停牌日（与交易日历对照） | 缺日必须有解释，不能是随机丢数 |
| 7 | 除权日已标记 | 每个 `adj_factor` 变化点都能对应到除权事件 |
| 8 | `adj_factor` 覆盖 | 空值 = 0，或已显式标记 DQ（不得静默当 1.0） |
| 9 | 异常涨跌幅 | 「日涨跌幅绝对值 > 20%」的行必须全部是除权日，否则查数据 |
| 10 | 时间范围 | 不超出 `end_date`；含当日 bar 时要截断 |

`scripts/build_universe.py --audit-only` 会自动产出 `runtime/exports/universe_coverage.md`（含上述大部分检查）。
