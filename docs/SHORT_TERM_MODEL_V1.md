# 短线模型 v1（研究阶段 · 已暂停）

> **状态：研究阶段，暂停开发；不作为交易/推荐依据。**
> 当前结论：**无可信样本外边际（负结果）**。本文如实记录 v1 结果、补充验证与暂停原因，
> 不做结果美化，也不建议继续在现有特征/样本上做参数调优（过拟合风险高）。

## 1. v1 定稿结论（Lead 真实数据实测）

| 项目 | 结果 |
|---|---|
| 样本 | 3 只标的（000001.SZ / 300750.SZ / 600519.SH），2021-10 ~ 2026-10，真实日线（不复权） |
| 训练/评估 | walk-forward 滚动训练 + purge 5 日，48 折 |
| OOS 命中率（未来 5 日 ≥ +2%） | **24.83%** |
| 基础概率（同标签随机命中） | **24.83%**（完全相同 → **零排序能力**） |
| 扣双边成本+滑点后 5 日期望 | **-0.22%** |
| Top 组组合最大回撤 | **-32.41%** |
| 自动判定 | `usable=False` → **不可用** |
| 特征重要性 | ATR/波动率、距 MA20 靠前，但均无预测力 |

根因判断（Lead）：① 样本太小（3 只股票）；② 标签二分类不平衡且区间市场整体下行；
③ 特征全为个股量价，缺少市场/板块状态与资金流信息。

## 2. 本轮补充验证（仍为负结果）

### 2.1 短线 v2 实验框架（已实现，未发现可用配置）

`strategy/short_term_v2.py` 实现了 Lead 要求的实验矩阵：5 种标签（5 日 ≥2%、3 日 ≥2%、
5 日截面 Top20%、5 日三分类、次日高开缺口）× 2 套特征（v1 量价 / v2 加市场状态+板块相对
强度+涨跌停邻近度+连续放量+量价背离）× 3 种模型（logistic / GBDT 分类 / GBDT 截面分位
回归），严格 walk-forward + purge。

**管线验证（3 只标的、2020-2026、47 折）**：OOS 命中率 24.25%（基础概率 45.69%）、
扣费期望 -0.29%。该结果仅用于验证“框架能跑通”，**样本只有 3 只、不具统计意义**；
但方向与 v1 一致：没有可用的正向排序能力。

### 2.2 全市场筛选器（50 只、2020-2026）同样无效

对“全市场 → 流动性 → 260 日量价 → 截面 z-score → 过热剔除 → Top N”规则做了严格分组回测
（50 只流动性好的 A 股、1,524 个截面、5 组、持有 5/10/20 日、扣 23bp）：

| 持有期 | RankIC | Top 组超额（t 值） | Top - Bottom |
|---|---|---|---|
| 5 日 | -0.0288 | +0.009%（t=0.12） | -0.237% |
| 10 日 | -0.0302 | +0.051%（t=0.49） | -0.386% |
| 20 日 | -0.0369 | -0.081%（t=-0.52） | -0.771% |

结论：**RankIC 为负、Top 组无超额、低分组反而略优**，规则打分无效（详见
`docs/SCREENER_VALIDATION.md`）。这进一步说明：当前“日频量价 + 动量/放量/突破”类信号
在该市场/周期上没有可交易边际，换模型（linear/GBDT/排序）也救不回来。

## 3. 为什么暂停

1. 用户优先级调整：项目进入**收尾阶段**，不再继续研究性开发；
2. v1/v2/筛选器三条独立验证均未发现可信 alpha，继续调参极易变成对样本的过拟合；
3. 若要继续，瓶颈在**数据与标签**（资金流、龙虎榜、事件、分钟级量价、行业中性化），
   而不是在现有特征上换模型或改权重；
4. 研究模块保留但**不得进入默认推荐/交易链路**，以免把未验证信号包装成买入建议。

## 5. 恢复条件与下一步（若未来重启）

只有同时满足以下判定线，才允许接入 UI/推荐：
1. 样本外命中率 **> 55%**（相对基础概率有显著提升，而非绝对命中率）；
2. 扣双边成本+滑点后 5 日期望 **> 0**；
3. Top 组组合最大回撤 **< 10%**，且多空/IC 稳健（RankIC ≥ 0.03 且 ICIR 合理）。

优先做（按性价比）：
1. **接新数据**：资金流、龙虎榜、公告事件、行业相对强度、分钟级量价（先解决数据，再换模型）；
2. **改标签**：未来 5/10 日超额收益分位 / 三分类，配合行业市值中性化 + purge/embargo；
3. **严格样本外**：2019 年前数据二次确认、分市场状态（牛/熊/震荡）分层评估、扣费后再比较；
4. **排序学习**：按日期分组的 ranking 目标（LTR）替代二分类/回归代理。
