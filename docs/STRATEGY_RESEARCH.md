# A 股短线交易策略手册（STRATEGY_RESEARCH）

> 版本 v1.0 · 2026-10-25 · 作者：量化策略研究员（子代理）· 面向 QuantDesk 日频短线系统
> 定位：把"市场大神/本土游资/开源项目"的方法，翻译成**能写进 `strategy/` 目录、能被现有回测引擎验证**的精确规则。
> 本文件是"研究输入"，不是"收益承诺"。所有策略在通过 §3 的样本外判定前，只能标记为**研究阶段**（BRIEF §2 合规口径）。

## 0 阅读前提（先看这一节，否则后面的公式会误读）

### 0.1 三条纪律

1. **不编数字**：本文件不出现任何"胜率 68%""年化 30%"之类无出处的数字。凡是引用他人业绩，一律标注"自述/赛事记录/**未独立审计**"；凡是估算，一律写清"这是算术推导，不是回测结果"。
2. **分级标注**：每条方法标 **A/B/C** 三级（见 §0.4），禁止把 C 级民间经验与 A 级学术结论并列陈述。
3. **可证伪优先**：定义必须写到"另一个人按同样代码能算出同样的信号"的程度；做不到的（如"主力意图""盘感"）一律进 §4.3 不可证伪清单。

### 0.2 字段字典（以本系统 `daily_bars` 实际落库字段为准）

来源：`quantdesk/core/models.py::DailyBarORM`、`quantdesk/data/akshare_provider.py`、`quantdesk/docs/DATA_SOURCES.md`（实测记录）。

| 字段 | 列名 | 口径 / 单位 | 可用性 |
|---|---|---|---|
| 开高低收 | `open/high/low/close` | 元，**不复权**原始价；复权由 `adj_factor` 换算 | ✅ 新浪主源 |
| 成交量 | `volume` | **股**（不是手） | ✅ |
| 成交额 | `amount` | 元（指数日线无此字段） | ✅ 个股 |
| 换手率 | `turnover_rate` | **%**（新浪返回小数，入库时 ×100） | ✅ |
| 后复权因子 | `adj_factor` | 离散除权日因子，需向后填充 | ✅（缺失时降级不复权） |
| 停牌标记 | `is_suspended` | bool | ✅ |
| 指数日线 | 同 OHLCV | 沪深300/上证/深证/创业板 | ✅ |
| 涨停/跌停价 | 派生 | `round(prev_close×(1+limit),2)`，limit 由板块+ST 决定 | ✅ 引擎内置 |
| 流通市值 | 派生 | `FLT_MV = close × volume ÷ (turnover_rate/100)`（元） | ⚠️ 反推，误差来自换手率四舍五入与股本变动 |
| 量比（真实口径） | — | 当日累计量 ÷ 过去 5 日**同时刻**均量，需分钟数据 | ❌ 日频只能用代理 `VR = volume/MA20(volume)` |
| PE/PB/总市值 | — | 东财快照 ProxyError → NaN | ❌ 当前不可得 |
| 主力资金流 | — | 东财 `push2his` 不可用 | ❌ 当前不可得 |
| 龙虎榜/游资席位 | — | 未接入；`datacenter-web` 部分可用但**未实测** | ❌ 不可依赖 |
| 申万/东财行业归属 | — | 行业接口不可用 | ❌ **板块轮动/真龙头无法实现** |
| 分钟线 / L2 盘口 | — | 不做 | ❌ |

> **结论**：本系统能实现的信号只依赖 **开高低收 + 成交量 + 成交额 + 换手率 + 复权因子 + 板块规则**。凡是需要行业归属、资金流、席位、盘口、分钟线的战法，本手册只能写"定义"，并明确标注**当前不可回测**。

### 0.3 符号约定（全文统一）

| 符号 | 定义 |
|---|---|
| `O,H,L,C,V,AMT,TR` | 当日开/高/低/收、成交量(股)、成交额(元)、换手率(%) |
| `r_t` | 当日涨幅 = `C_t/C_{t-1} - 1` |
| `MA_n` | `mean(C, n)`，含当日 |
| `VMA_n` | `mean(V, n)`，含当日 |
| `VR_t` | 日频量比代理 = `V_t / VMA_20` |
| `HH_n / LL_n` | **前** n 日（不含当日）最高/最低：`max(H_{t-n..t-1})`、`min(L_{t-n..t-1})` |
| `BRK_n` | 突破幅度 = `C_t / HH_n - 1` |
| `AMP` | 振幅 = `(H_t - L_t) / C_{t-1}` |
| `ATR14` | 平均真实波幅（TA-Lib 口径） |
| `RS_252` | 距 52 周高点 = `C_t / max(H, 252)` |
| `lim` | 涨跌幅限制：主板 10%、创业板/科创板 20%、ST 5%、北交所 30% |
| `P_lim` | 涨停价 = `round(C_{t-1} × (1+lim), 2)`；`ZT_t = 1[C_t ≥ P_lim - 0.005]` |
| `LB_t` | 连板数 = 截至 t 的连续 `ZT=1` 天数 |
| `position_pct` | 单票目标市值 ÷ 账户总资产（引擎参数，默认 10%） |

### 0.4 可信度分级

| 级别 | 含义 | 例子 |
|---|---|---|
| **A** | 有学术论文/公开可复核数据支持，方法有明确统计检验 | 动量效应、52 周高点效应、MAX 彩票效应、purged walk-forward 方法论 |
| **B** | 书籍/赛事/长期从业者自述，逻辑自洽但**无独立审计**战绩 | Livermore、O'Neil、Minervini、Darvas、Weinstein、PTJ、Larry Williams |
| **C** | 民间经验、博客、事后叙事，定义含糊或无法证伪 | 打板"情绪周期"、龙头战法、缠论"背驰"、主力吸筹意图 |

### 0.5 数据现实（决定了"能验证什么"）

- 现有库：**只有 3 个标的**（000001.SZ / 300750.SZ / 600519.SH），2021-10-25 ~ 2026-10-23，各 **1212 根**日线，无缺口、全部 `source=akshare`（见 `runtime/exports/data_coverage.md`）。
- 含义：**当前无法验证任何横截面（截面排序/选股）策略**——3 只票算不出有意义的截面分位。所有"排名前 10%"类规则必须先扩池（§3.1）。
- 全 A 扩池的工程量级（估算）：约 5000+ 标的 × 单请求 ~1s + 300ms 限流 ≈ **1.5~2 小时/次全量**；日增量按当日活跃标的计，仍是分钟级~小时级。这是"要不要做横截面策略"的第一道成本。
- 涨跌停不可成交：引擎在涨停价/跌停价**拒绝成交**（fail-closed），因此**任何"打板"策略在回测中都无法以涨停价买入**，只能退化为"次日开盘买入"近似（§4.4）。

## 1 信号库

### 1.1 海外交易员/流派要点

> 每个流派按：核心思想 → 可量化规则（→ 对应信号表 A 的编号）→ 适用市场与周期 → 已知胜率/风险 → 可验证方式。
> **统一免责**：以下人物的战绩全部为**自述、传记或赛事记录，未独立审计**，本文件不引用其收益率数字作为任何证据。

#### 1.1.1 Jesse Livermore —— 关键点 / 趋势跟随（B 级）

- **核心思想**：只在"关键点"（前高、整数关口、长期整理区上沿）被**带量突破**时介入；先小仓试探（probe），对了加仓，错了立刻认错；永不摊平亏损；只做领涨板块的领涨股。
- **可量化规则**：关键点 → `BRK_n > 0` 且 `VR_t ≥ 1.3`（信号 A1）；试探仓 → 首仓 1/3，浮盈 ≥ 1R 后加至满仓（信号 A15 的仓位规则）；止损 → 单笔亏损 ≤ 1R。
- **适用市场与周期**：趋势市；日线，持有 5–20 日。
- **已知胜率/风险**：**无审计交易记录**（《股票作手回忆录》是文学化传记，作者 Lefèvre 并非 Livermore 本人）；公开史实包含多次破产 → 只能作为"方法论"引用，**不可作为收益证据**。方法层（截断亏损、让利润奔跑）与趋势跟随的实证结论方向一致。
- **可验证方式**：事件研究——每次 `BRK_n` 触发后，统计未来 5/10/20 日**超额收益**（相对同期全市场等权中位数），并按"指数是否在 MA200 之上"分层；若只在某一制度下有效，就不是普适 alpha。

#### 1.1.2 William O'Neil —— CANSLIM（B 级）

- **核心思想**：成长股 + 突破 + 量能 + 市场方向。C（当季盈利加速）/A（年度盈利增长）/N（新高、新产品）/S（流通盘与量能）/L（龙头而非补涨）/I（机构增持）/M（大盘方向）。
- **可量化规则**：**只有 N/S/L/M 可用日线数据实现**——L → 相对强度排名（A2）、N → 平台 pivot 突破（A3）、S → 量能确认（`V_t ≥ 1.5×VMA50`）、M → 分布日计数（A4）+ Follow-through Day（A5）。
- **适用市场与周期**：结构性牛市；持有 10–30 日，卖出规则为"亏 7~8% 止损、赚 20~25% 了结、跌破 50 日均线放量则清仓"。
- **已知胜率/风险**：C/A/I 三个维度依赖财报与机构持仓数据，**本系统当前无财报接口、无机构持仓**（§0.2），因此**CANSLIM 只能被实现成"价格+量能"的子集**，不是原教旨 CANSLIM。原方法本身是商业出版物（IBD）体系，无同行评审验证。
- **可验证方式**：把 L/S/N 分别做单因子分层测试（五分位超额收益），再做组合；M 作为开关变量测"开/关 M 过滤器"的差异（配对比较）。

#### 1.1.3 Mark Minervini —— SEPA / VCP（B 级）

- **核心思想**：只买处于**第二阶段上升趋势**的股票（趋势模板 8 条）；在**波动收缩（VCP）**末端、成交量枯竭后的 pivot 突破处买入；风险优先，单笔风险 1.25%–2.5% 账户权益。
- **可量化规则**：趋势模板 → 信号 A6（`C>MA150>MA200`、`MA150` 上行、`C>MA50`、`C ≥ 1.3×LL_252`、`C ≥ 0.75×HH_252`）；VCP → 信号 A7（3 段回撤依次收敛 `DD1>DD2>DD3`、量能依次收敛、突破最后收缩高点 + 量能放大）。
- **适用市场与周期**：成长股趋势市；持有 5–20 日（短线）到 3 个月（波段）。
- **已知胜率/风险**：曾获美国投资冠军赛（US Investing Championship）冠军，属**赛事记录 + 自述**，非审计账户；方法本身的"收缩—突破"结构没有独立学术检验。已知风险：**趋势模板在长期下行市几乎全市场不满足**（A 股 2022–2024 属此类），会导致长期空仓——这是特性不是缺陷，但必须提前说明。
- **可验证方式**：先单独验证趋势模板的**过滤价值**（模板内 vs 模板外的突破信号胜率差），再验证 VCP 增量；两者必须用**同一批突破事件**做消融实验（ablation），否则无法区分"是模板有效"还是"突破本身有效"。

#### 1.1.4 Nicolas Darvas —— 箱体理论（C/B 级）

- **核心思想**：股价在"箱体"（箱顶=压力、箱底=支撑）内震荡；**带量突破箱顶**即买入，箱顶变支撑（止损上移）；跌回箱体即失败离场。
- **可量化规则**：箱体 → 最近 N 日 `(HH_N - LL_N)/LL_N ≤ 12%`；突破 → `C_t > HH_N` 且 `V_t ≥ 1.5×VMA20`；止损 → `box_top × 0.98` 或 `LL_N`（信号 A8）。
- **适用市场与周期**：单边趋势中的中继整理；持有 10–40 日。
- **已知胜率/风险**：书名为《我如何在股市赚了 200 万美元》，属**自述且无法复核**（1950 年代电报交易，无成交记录）→ C 级证据。已知风险：箱体宽度阈值（12%）直接决定信号数量与质量，是**自由参数**，极易过拟合。
- **可验证方式**：箱体宽度做参数曲面（8%/10%/12%/15% × N=15/20/30/40），看样本外是否出现"某个窄参数区间普遍为正"的平坦高原，而不是单个孤立峰值（参数稳健性，对应 `config.yaml::research.param_robustness_pct: 20`）。

#### 1.1.5 Stan Weinstein —— 四阶段分析（B 级）

- **核心思想**：任何标的都在四个阶段循环：①筑底（30 周均线走平）②上升（价在 30 周均线上方且均线上行、放量）③做头（高位宽幅震荡）④下跌（跌破 30 周均线）。**只在第二阶段持有**。
- **可量化规则**：`MA150`（≈30 周）作为阶段线；阶段 2 = `C > MA150` 且 `MA150_t > MA150_{t-20}` 且突破 30 周区间高点；阶段 4 = `C < MA150` 且 `MA150` 下行 → 无条件离场（信号 A9）。
- **适用市场与周期**：周线级别的中期趋势；持有 1–6 个月（对"短线系统"偏慢，只能作为**风控/持仓过滤**）。
- **已知胜率/风险**：书籍体系，无审计业绩；周线信号滞后，A 股短线圈基本不用。
- **可验证方式**：作为 S1 策略的**离场规则**做 A/B 对比（有/无阶段 4 离场），看最大回撤与年化换手的差异。

#### 1.1.6 Richard Wyckoff —— 吸筹/派发（C 级）

- **核心思想**：把价格行为解读为"综合人（Composite Man）"的吸筹（accumulation）与派发（distribution）：PS→SC→AR→ST→Spring/Shakeout→SOS→LPS，量价关系（effort vs result）揭示供需失衡。
- **可量化规则**：可被算法化的只有骨架——区间识别（`N=30~60`，宽度 ≤15%）+ **Spring**（`L_t < RL` 但 `C_t > RL` 收回，且缩量）+ **SOS**（`C > RH` 且 `V ≥ 2×VMA20`）（信号 A10）。"creek/ice/LPS"等概念无法稳定定义。
- **适用市场与周期**：震荡末期的反转；持有 5–20 日。
- **已知胜率/风险**：**事后叙事偏差极重**——同一段走势，不同人事后可以标注成完全不同的 Wyckoff 结构。1930 年代课程体系，无任何可复核业绩。**属于"不可证伪"高风险区**（§4.3）。
- **可验证方式**：只有把"Spring"写成**参数固定的布尔条件**后才可验证；且必须报告**信号数量**——如果 5 年只触发 12 次，任何胜率都无统计意义（§3.4 功效表）。

#### 1.1.7 Larry Williams —— 波动突破（B/C 级）

- **核心思想**：用"昨日振幅"预判今日的突破阈值——`买入触发价 = 今日开盘 + k × 昨日振幅`（k 常取 0.5）；收盘前平仓，不留隔夜。
- **可量化规则**：`TRG_up = O_t + k×(H_{t-1} - L_{t-1})`，`TRG_dn = O_t - k×(H_{t-1} - L_{t-1})`（信号 A11）；k ∈ [0.4, 0.6]。
- **适用市场与周期**：日内（intraday）；A 股 **T+1 无法当日平仓**，只能改成"次日开盘触发 / 持有 1–3 日"。
- **已知胜率/风险**：1987 年世界期货交易冠军赛冠军（赛事记录），但**日内高杠杆战绩不可迁移到 A 股日频 T+1 环境**；改造后 alpha 是否残留**未验证**。已知风险：突破阈值是**自由参数**，且"当日最高价触及触发价"与"收盘确认突破"是两种完全不同的信号（本系统只能用后者，因为日线数据无法判断触发先后）。
- **可验证方式**：对比三种实现——①收盘确认突破 ②次日开盘无条件买 ③次日开盘且需 `O_{t+1} > TRG_up`；三者差异本身就是"日频化损耗"的度量。

#### 1.1.8 Paul Tudor Jones —— 风控优先 / 200 日均线（B 级）

- **核心思想**：先定风险再谈收益（单笔亏损 ≤1% 权益、风险回报比 ≥3:1、亏损立刻认错）；用 **200 日均线**定义多空制度，制度不利时不参与。
- **可量化规则**：制度 → `REG = C_idx/MA200(C_idx) - 1`，`REG > 0` 才允许开多（信号 A13）；仓位 → `qty = (0.01 × 权益) / (C_t - stop)`；离场 → 触及 stop 无条件走。
- **适用市场与周期**：跨资产宏观；日线，制度级。
- **已知胜率/风险**：连续多年正收益属媒体/自述，无审计。已知风险：**均线制度在震荡市反复 whipsaw**（A 股 2023 年多次穿越 MA200），且 200 日线极度滞后。
- **可验证方式**：把 A13 当**开关变量**做配对检验：同一批突破信号，分别在 `REG>0` 与 `REG<0` 下统计超额收益差；同时统计"制度翻转次数/年"，翻转越频繁，过滤器的交易成本越高。
